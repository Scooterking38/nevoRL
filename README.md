**NevoRL**
===============

Automate your neural network modeling with ease.

**Features**

* Simplifies the process of building and training neural networks using Python
* Supports various neural network architectures and configurations
* Provides a modular design for easy customization and extension

**Tech Stack**

* Python 3.8+
* NumPy
* SciPy
* TensorFlow

**Installation**

1. Clone this repository: `git clone https://github.com/nevoRL.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the code: `python nevoRL.py`

That's it! You're now ready to start using NevoRL for your neural network modeling needs.
